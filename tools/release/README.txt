REBIRTH: BREAK THE BOX - early prototype

Starting: unzip everything (don't run it from inside the zip) and double-click Rebirth.exe.
The "data_Rebirth_windows_x86_64" folder must stay next to Rebirth.exe.
Windows may say "Windows protected your PC": click "More info" > "Run anyway".
That is only because the exe isn't signed.

Controls (defaults; change them under Esc > Controls)
  W A S D / Space / C   move, up (jump), down          Mouse         look
  Q / E                 roll                           Shift         sprint (walking on planets)
  X / Z / L             jetpack / dampeners / light    F             use (cockpit, machine, storage)
  1-0 / mouse wheel     hotbar / next page             R / T / G     turn block / block shape
  Left mouse            place / drill                  Right mouse   remove block
  Tab                   inventory                      N             Nexus (overview, bots)
  B                     Forge (designer)               V / Alt       first/third person / look around
  F5 / F9               save / reload                  Esc           menu

Tip: start with "New game - with tutorial".
Slow PC or laptop? Esc > Graphics > Low (or lower the render scale).
Saves live in %APPDATA%\Godot\app_userdata\Rebirth
